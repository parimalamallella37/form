# Parent Teacher Conference Form

A responsive and user-friendly web form built with HTML5 and CSS3 for scheduling parent-teacher conferences. The form collects student information, parent/guardian details, preferred contact methods, and additional discussion topics to help teachers prepare for meetings.

## Features

* Clean and responsive design
* Student information section
* Parent/Guardian information section
* Custom-styled radio buttons for contact preferences
* Additional notes textarea
* Form validation using HTML5 required attributes
* Modern UI with a dark theme and centered layout
* Interactive submit button hover effect

## Technologies Used

* HTML5
* CSS3
